## Summary

Astro adalah framework web yang dirancang untuk menghasilkan halaman dengan JavaScript seminimal mungkin, menjadikannya pilihan yang sangat kuat untuk landing page yang mengutamakan kecepatan dan SEO.

## Introduction

![](/images/uploads/Copilot_20260724_114015.png)

Ketika bisnis membutuhkan landing page, kecepatan bukan lagi sekadar nilai tambah — kecepatan adalah syarat. Setiap detik tambahan waktu muat berpotensi menurunkan tingkat konversi. Di sinilah Astro menjadi relevan sebagai pilihan teknis, bukan sekadar tren.

## What Is Astro?

Astro adalah framework web modern yang berfokus pada pengiriman konten dengan JavaScript minimal. Berbeda dengan framework seperti React atau Vue yang secara default mengirim seluruh aplikasi sebagai JavaScript ke browser, Astro merender halaman menjadi HTML statis terlebih dahulu, lalu hanya menambahkan JavaScript pada bagian yang benar-benar memerlukan interaktivitas.

## Why It Matters

Bagi landing page, sebagian besar konten bersifat statis: teks, gambar, dan tombol CTA. Interaktivitas kompleks jarang dibutuhkan di seluruh halaman. Mengirim JavaScript penuh seperti pada SPA konvensional untuk kebutuhan ini adalah pemborosan bandwidth dan waktu proses di sisi pengguna.

## Benefits

- **Waktu muat lebih cepat** karena ukuran JavaScript yang dikirim jauh lebih kecil.
- **Skor Core Web Vitals lebih tinggi**, yang juga berdampak positif pada peringkat SEO.
- **Fleksibilitas komponen**, karena Astro tetap mendukung React, Vue, Svelte, atau Solid jika dibutuhkan di bagian tertentu.
- **Struktur proyek yang sederhana**, cocok untuk tim kecil maupun studio independen seperti Wonderweb.

## Examples

Sebuah landing page produk dengan galeri gambar, form kontak, dan animasi scroll dapat dibangun sepenuhnya dengan Astro, di mana hanya form dan animasi yang menggunakan JavaScript — sisanya tetap statis dan sangat ringan.
